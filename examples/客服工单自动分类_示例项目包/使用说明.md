# 示例项目包：客服工单自动分类

这是一个**虚构的**示例项目，用来体验「AI 产品工作台」一次解析多个文件。所有数字都是示例值。

包里有 6 份不同格式、不同阶段的文件：

| 文件 | 格式 | 应被识别为 |
|---|---|---|
| 01_需求描述.md | Markdown | 需求描述 |
| 02_立项说明BRD.md | Markdown | BRD |
| 03_PRD_工单自动分类.docx | Word | PRD |
| 04_PRD评审会议纪要.txt | 纯文本 | 评审纪要 |
| 05_离线评测报告.pdf | PDF | 评测报告 |
| 06_评测结果明细.csv | CSV | 评测报告 |

用法：在工作台点「新建项目」，把这 6 个文件一次全部选上（或拖进去），点「分析并拆解」。

预期结果：系统以进度最靠后的评测报告为准，判断项目已经到了第 7 阶段「评测验证」，前面的阶段标记为"已有产出，待确认"。

不要上传这个「使用说明.md」本身，它不是项目文档。
