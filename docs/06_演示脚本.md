# 演示脚本

## 一、演示前准备（2 分钟）

1. 用 Chrome 或 Edge 双击打开 `demo/ai-pm-workbench-demo.html`，或者运行 `node server.js` 后打开 `http://localhost:3000`。
2. 窗口最大化，浏览器缩放 100%（Ctrl+0 或 Cmd+0）。宽度不够时会变成手机布局，左侧竖向阶段会消失。要投屏就提前用投屏分辨率试一次。
3. 点右上角「重置示例项目」，确认。每次演示前都做一次。
4. 关掉其他标签页和消息通知。

准备好后应该看到：左侧 10 个阶段竖排，中间是「第 7 阶段 评测验证」，右侧有深色按钮「推进关卡：是否达标」。

## 二、三分钟主线

| 时间 | 操作 | 你会看到 | 可以这样说 |
|---|---|---|---|
| 0:00–0:20 | 不点任何东西 | 第 7 阶段的 3 个步骤都已完成；漏检率 22% 标着未达标 | "这是示例项目，数字是示例值。任务都做完了，但任务做完不代表能上线。" |
| 0:20–0:50 | 点「推进关卡：是否达标」 | 7 条规则检查，漏检率打红叉（22%，标准 ≤ 15%），红字"拦截"；左侧第 7 阶段变红 | "能不能往下走，看的是立项时定好的标准，不看进度。" |
| 0:50–1:30 | 讲 AI 建议，不点按钮 | 建议标着"预设演示建议"，写成待验证的假设，有验证方法和备选路线 | "AI 给的是可以验证的判断，不是结论。演示版这条是预设的，接上模型后由模型生成。" |
| 1:30–2:00 | 点右下「采纳建议：回到第 6 阶段」 | 中间变成第 6 阶段，多一条返工步骤；决策记录多出"构建依据从修订 1 变为修订 2" | "决定变成了返工任务。改完构建，之前测出来的成绩就不能再用了。" |
| 2:00–2:40 | 决策记录里点「查看当时依据」 | 当时的规则明细、指标表、AI 完整建议、当时的阶段产出 | "以后任何人问为什么返工，打开这里就能看到当时的数字、标准和理由。日志记录发生了什么，这里记录的是做决定的依据。" |
| 2:40–3:00 | 只说不点 | — | "也可以强制放行，但必须写原因和批准人，项目会被永久标上风险。" |

## 三、追问时的补充演示

**"返工之后呢？"**：把第 6 阶段的返工步骤标为完成，点「完成本阶段，进入第 7 阶段」。评测结果显示"已过期"并被锁定，点「清空并按当前依据重新录入」，填入漏检率 12、动作准确率 90，点「推进关卡」。指标趋势卡片出现 22 到 12 的折线，规则全部满足。

**"谁来批准？"**：接着点「采纳建议：进入第 8 阶段」，弹窗要求填写批准人和意见。说明："工具是单人用的，不做审批流程，但每次放行都写明是谁批准的。"

**"能拿给业务方看吗？"**：点「导出」→「决策报告」，下载一份 Markdown，包含关卡状态、风险与例外、每次决定的依据、指标趋势。只想发某一次，在依据弹窗底部点「导出这次决定」。

**"如果数据改了呢？"**：回到第 7 阶段，把漏检率改成 99。决策记录出现"第 7 关失效"，右侧出现黄色提示"有前置关卡当前无效"。

**"新项目怎么开始？"**：点「新建项目」，把 `examples/客服工单自动分类_示例项目包` 里的 6 个文件一起拖进去（不含使用说明），点「分析并拆解」。系统逐个识别文件类型，以评测报告为准判断当前工作阶段是第 7 阶段，前面的阶段标为未核验。Word 和 PDF 解析需要联网。

## 四、常见追问与回答方向

| 追问 | 回答方向 |
|---|---|
| 为什么不用表格或项目管理工具？ | 普通工具能记录任务，但不会因为指标不达标拦住推进，也不会在依据变化后让旧结论失效。价值在关键决策的依据，不在阶段数量 |
| 自己给自己设关卡有什么用？ | 价值在留下可以拿给别人看的依据：批准人、当时的数字、标准、理由，可以导出成报告 |
| 数据是手填的，规则有什么意义？ | 规则检查的是数据是否满足事先约定，不认证真实性；通过修订号、快照和推翻留痕提高可核查性，不宣称不可篡改 |
| AI 到底做了什么？ | 演示版由规则模板生成，用来验证交互和控制逻辑；接入模型后负责文档判断、拆解和建议。模型建议的质量还没有系统评测 |
| 有没有用户验证？ | 如实说明还没有；下一步是找几位产品经理按主线试用，记录卡点 |
| 和 GitHub 上的同类项目比怎么样？ | 参考过带关卡的产品管理系统和 promptfoo 这类评测工具，本项目的切入点是把评测结果变成产品经理可视化的决策关卡，见 `docs/05_竞品与界面调研.md` |
| 代码是你写的吗？ | 如实说明是在 AI 辅助下完成编码；需求、规则、取舍和两轮评审的处理由自己决定，过程都在 docs 里 |

## 五、出问题时怎么办

| 情况 | 处理 |
|---|---|
| 状态乱了 | 点「重置示例项目」 |
| 页面变成手机布局 | 窗口最大化，缩放调回 100% |
| Word 或 PDF 读不出来 | 需要联网；或者改传 Markdown、TXT，或把内容粘贴到补充说明 |
| 弹窗没反应 | 检查必填项（批准人、原因），错误提示在弹窗底部 |
| 看不到导出按钮 | 在线体验链接不支持下载，用本地文件打开 |
